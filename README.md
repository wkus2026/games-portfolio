# Games Portfolio 🎮

Een Poki.com-achtige website voor mijn Unity platformer spelletjes.

## Features

- 📱 Responsive design (mobiel, tablet, desktop)
- 🎮 Game cards met hover effects
- ⭐ Rating en plays teller
- 🎨 Modern gradient design
- ⚡ Smooth animations
- 📊 About section met stats

## Project Structuur

```
├── index.html       # Hoofd HTML pagina
├── styles.css       # Styling met CSS Grid
├── script.js        # Interactiviteit
└── README.md        # Dit bestand
```

## Hoe te gebruiken

1. Clone de repository
2. Open `index.html` in je browser
3. Personaliseer de spelletjes kaarten met je eigen games

## Aanpassingen maken

### Je spelletjes toevoegen:

1. Vervang de placeholder images in `index.html`
2. Voeg de juiste spelletje informatie in
3. Update de beschrijvingen en ratings

### Spelletjes inbedden:

- Voor WebGL builds: Voeg iframes toe in de HTML
- Voor externe links: Update de play buttons met links
